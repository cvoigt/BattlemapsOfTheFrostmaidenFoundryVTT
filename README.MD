# Battlemaps Of The Frostmaiden
This Module for **Foundry v14+** provides fully build Scenes based on the [Battlemaps Of The Frostmaiden](https://github.com/cvoigt/BattlemapsOfTheFrostmaidenFoundry).

It is **system-agnostic** even though D&D 5e/5.5e are recommended.

Scenes contain proper **Levels**, **Walls**, **Animated Doors**, **Lights** and **Automations** that can be triggered by the GMs based on the Adventure Lore and Map setup.

This Module **does not provide** *Actors*, *Playlists*, *Macros* or specific references to the *Foundry Game System* that is used.

## High-Res Versions
Lossless PNG versions and Dungeondraft Source Files for all assets are available at https://github.com/cvoigt/BattlemapsOfTheFrostmaidenFoundry for:
- all Modular Maps from this Module as lossless PNG
- the original Dungeondraft source files

## Recommended Modules
- **Mini Light Switch** by Stephen Garrett
  - Requires Tagger Module
  - easy switch for light sources in all scenes
- **Monk's Active Tile Triggers** by Ironmonk
  - Requires Tagger Module
  - automation for GMs to show/hide props on demand
- **Tagger** by Wasp
  - allows better identification of placeables
