# Battlemaps Of The Frostmaiden
This Module for **Foundry v14+** provides an **Adventure Compendium** with fully build Scenes based on the [Battlemaps Of The Frostmaiden](https://github.com/cvoigt/BattlemapsOfTheFrostmaidenFoundry).

It is **system-agnostic** even though D&D 5e/5.5e are recommended.

Scenes contain proper **Levels**, **Walls**, **Animated Doors**, **Lights** and **Automations** that can be triggered by the GMs based on the Adventure Lore and Map setup.

This Module **does not provide** *Actors*, *Playlists*, *Macros* or specific references to the *Foundry Game System* that is used.

## Usage
After activating the Module in your Foundry World you can find the **Adventure Compendium** where you find all Compendiums:
![Where to find the Adventure Compendium](/assets/artwork/journals/adventure.webp)

You can then choose which Chapter to import the Scenes for by simply clicking on them.

> ⚠️ **Importing over existing Scenes with modifications** ⚠️
> I **<u>highly</u>** recommend you make a backup before replacing Scenes that you've previously imported and/or modified.
> 👉🏼 Please read the **CHANGELOG** to find out what was changed from the last Module Version and decide what you need/want to import again

![Importing the Scenes](/assets/artwork/journals/adventure%20scene%20import.webp)

> ℹ️ *A separate import exists for "Documentation and Help" which contains more detail information on how the Scenes are built and what you can expect as a GM.*

## Required Modules
You will be prompted to install the required Modules upon installation of this Module.
- **Monk's Active Tile Triggers** by Ironmonk
  - Requires Tagger
  - automation for GMs to show/hide props on demand
- **Tagger** by Wasp
  - allows better identification of placeables

## Recommended Modules
- **Mini Light Switch** by Stephen Garrett
  - Requires Tagger
  - easy switch for light sources in all scenes
